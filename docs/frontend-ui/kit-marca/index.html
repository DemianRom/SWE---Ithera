07 / SISTEMA

Reglas para construir.

Una base práctica para mantener coherencia en React y hacer crecer la interfaz sin perder claridad.

ESPACIADO

Ritmo de 4 px

Usa 4, 8, 12, 16, 24, 32, 48 y 64 px. Prioriza 24 px dentro de tarjetas y separación clara entre secciones.

INTERACCIÓN

Acciones visibles

Controles de al menos 44 × 44 px, foco de teclado visible, etiquetas persistentes y confirmación de acciones.

CONTENIDO

Dinero sin dudas

Indica moneda, signo y contexto. No presentes un pago registrado como transferencia procesada.

ADAPTACIÓN

Primero móvil

Una columna en móvil; dos o tres cuando exista espacio. Evita el desplazamiento horizontal de la página.

ACCESIBILIDAD

Contraste y foco

Texto normal con contraste mínimo 4.5:1, controles distinguibles y movimiento reducido si se solicita.

CONSISTENCIA

Una misma ruta visual

Usa tokens semánticos, radios de 12–28 px, botones con esquinas suaves e iconos de una sola familia. Evita colores arbitrarios por pantalla.

Cómo llevarlo al producto

Estas reglas orientan el diseño; su cumplimiento debe comprobarse al implementar y probar Traveling.

Estado y respuestaInforma si se está guardando, si terminó o si hubo un problema.
Lenguaje cercanoHabla de gastos, pagos y saldos; identifica siempre la moneda.
Control y salidaPermite cancelar, volver y corregir. Ofrece deshacer cuando sea posible.
ConsistenciaUsa las mismas etiquetas, estilos y ubicación para acciones equivalentes.
PrevenciónValida montos y repartos; confirma antes de eliminar información.
ReconocimientoMantén visibles nombres, importes, participantes y etiquetas.
FlexibilidadPermite usar teclado y filtros para quienes gestionan muchos gastos.
Enfoque visualDestaca el saldo y la siguiente acción; reserva los detalles secundarios.
RecuperaciónExplica el error junto al campo e indica cómo solucionarlo.
Ayuda contextualAclara el reparto junto al control y ofrece ayuda cuando sea necesaria.
