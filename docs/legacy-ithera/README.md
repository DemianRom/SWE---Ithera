# Material historico de Ithera

Traveling nace de **Ithera** ([ITHERAADS/ITHERA](https://github.com/ITHERAADS/ITHERA)), el proyecto
original de la unidad de aprendizaje Analisis y Diseno de Sistemas (ESCOM IPN, ciclo 2026/2, grupo
5CM3). Cuando el proyecto se dividio en dos equipos, este repositorio quedo como la version del
Equipo 2 (cuentas compartidas del viaje).

Esta carpeta conserva, sin cambios, los entregables de Ithera. **No describen el alcance actual de
Traveling**: incluyen modulos que se quitaron (busqueda de vuelos y hospedajes, propuestas y
votaciones, mapas, agendas de subgrupos y checkout). La documentacion vigente empieza en
[../README.md](../README.md).

## Creditos

El codigo base (cuentas, viajes, integrantes, itinerario, presupuesto, chat y notificaciones) fue
desarrollado por el equipo de Ithera. El historial completo de commits se conserva en este
repositorio.

## Reglas

- No editar estos archivos: son evidencia historica.
- Si algo de aqui se vuelve vigente para Traveling, se reescribe en la carpeta correspondiente de
  `docs/` y se enlaza desde alli.
